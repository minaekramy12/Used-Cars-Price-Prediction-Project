# 🚗 Used Cars Price Prediction

A complete Machine Learning project for predicting used car prices using Python and Scikit-learn.

The project covers the entire machine learning workflow, including data cleaning, exploratory data analysis (EDA), hypothesis testing, feature engineering, model building, and model evaluation.

---

## 📊 Dataset

- Source: Kaggle Used Cars Dataset
- Rows: +4,000
- Target Variable: `price`

---

## 📌 Project Workflow

### ✅ Data Cleaning

- Handled missing values
- Standardized categorical values
- Cleaned transmission categories
- Cleaned fuel type values
- Extracted:
  - Horsepower (HP)
  - Engine Size
  - Number of Cylinders
- Saved the cleaned dataset

---

### ✅ Exploratory Data Analysis (EDA)

Performed analysis on both categorical and numerical variables.

Examples:

- Brand vs Price
- Fuel Type vs Price
- Transmission vs Price
- Mileage vs Price
- Horsepower vs Price
- Engine Size vs Price
- Number of Cylinders vs Price

Key insights were extracted for each feature.

---

### ✅ Hypothesis Testing

Applied statistical tests including:

- Independent Samples t-test
- One-Way ANOVA
- Pearson Correlation
